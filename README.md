# Каштан — эко кофейня (концепт сайта)

Статичный сайт без сборки: `index.html`, `style.css`, `script.js`, логотипы в SVG и фото в WebP. Все файлы лежат в одной папке.

## Выложить на GitHub Pages
1. Создайте репозиторий и загрузите в корень все файлы из архива.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

## Что уточнить у кофейни перед запуском
- Тексты блоков «С чего начать» и «О нас» — черновые, по меню и фото.
- Цены взяты из меню в их ВК — сверить с актуальными.
- Фото вырезаны со скриншотов Яндекс Карт (до ~800 px) — для запуска попросить оригиналы.
- Телефон +7 937 977-87-55 и ссылка на ВК — из открытых источников, проверить.

## Как устроено
- Статус «Открыто / Закрыто» считается по времени Энгельса (Europe/Saratov) и графику 08:00–21:30.
- Меню переключается вкладками; цены в `index.html`, в блоках `.mrow`.
- Анимации отключаются, если в системе включено «уменьшить движение».

## Фото и иллюстрации меню
Файлы `photo-*.webp` — сгенерированные фото позиций с прозрачным фоном.
Для разделов без фото (чай, вафли, сэндвичи, добавки) пока стоят иллюстрации `art-*.svg`.
Чтобы заменить: положите `photo-tea.webp`, `photo-waffle.webp`, `photo-sandwich.webp` или `photo-carton.webp` и поменяйте путь в `index.html`.

### Иллюстрации
Файлы `art-*.svg` — линейные иллюстрации к каждому разделу меню (рисованные, условные).
Их можно заменить фото-вырезками на прозрачном фоне: положите PNG/WebP с тем же именем
(например `art-iced.webp`) и поменяйте расширение в `index.html`.
